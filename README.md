# Agenda de Contatos Java

Sistema de agenda de contatos desenvolvido em Java com menu interativo no console.

## Funcionalidades
- Adicionar contato (nome e telefone)
- Listar contatos em ordem alfabética
- Buscar contato por nome
- Remover contato por nome

## Como usar
1. Execute o arquivo `Main.java`
2. Escolha uma opção no menu
3. Siga as instruções na tela
